# vTSFM presentation figures

Each figure is available as a vector PDF for the paper and as a 2,112 × 1,089 PNG for slides. The tables below use previously published experiments. The revision, device and measurement boundary matter when comparing results.

| Figure | What was measured | Evidence |
| --- | --- | --- |
| [Serving across three models](01-serving.pdf) · [PNG](01-serving.png) | Native FastAPI HTTP and vTSFM whole-forecast fusion on an A100 at `9cde2f1`. The left panel uses one outstanding B1/C2048/H96 Chiller 6 request. The right uses the highest tested Poisson arrival rate at which every request completed and every repeat met p99 ≤ 500 ms. “No tested rate qualified” is an observed test outcome. | [Issue #51, W1 and W3](https://github.com/vinli0921/vTSFM/issues/51) |
| [TimesFM graphs](02-timesfm-cuda-graphs.pdf) · [PNG](02-timesfm-cuda-graphs.png) | Fixed B2/C512/H1024, one outstanding request, A100. Each of four modes completed 300 timed requests in the three retained rounds. Sampled peak residency includes the held graph memory. | [Matched HTTP report](https://github.com/vinli0921/vTSFM/blob/1df1c05/docs/baselines/2026-11-17-timesfm-graph-http/README.md) |
| [Moirai attention](03-moirai-attention.pdf) · [PNG](03-moirai-attention.png) | Upstream and fused univariate attention in an admitted B8/C7168/H1024 HTTP request on an RTX A6000 at `bd1eca2`. The right panel uses the worker’s peak allocated memory in GiB. | [Issue #24 qualification](https://github.com/vinli0921/vTSFM/issues/24#issuecomment-6935265127) |
| [Toto compilation](04-toto-compilation.pdf) · [PNG](04-toto-compilation.png) | The A100 study at `b3b74b0` measured shipped guarded compilation in two orders. A separate earlier RTX A6000 pilot measured whole-forecast compilation. Each panel has its own eager control. Hardware, revision and scope differ between panels. | [Shipped scope](https://github.com/vinli0921/vTSFM/issues/17) · [Whole-forecast pilot](https://github.com/vinli0921/vTSFM/issues/17#issuecomment-6968665132) |
| [TimesFM block scheduling](05-timesfm-blocks.pdf) · [PNG](05-timesfm-blocks.png) | Two campaigns replayed the same 100-request MetroPT burst, four slots, B2/C512/H1024. The right panel has six counterbalanced arm orders. All 1,800 responses passed nine-quantile parity. | [Decode/prefill ablation](https://github.com/vinli0921/vTSFM/issues/51#combined-timesfm-h1024-results-from-prs-80-and-81) · [Final comparison](https://github.com/vinli0921/vTSFM/pull/83) |
| [Toto inference fast path](06-toto-runtime.pdf) · [PNG](06-toto-runtime.png) | B4/C128/H96 served over one vLLM slot on an A100, with one or four clients. Each arm combines 200 completed requests per client count. The candidate includes inference-only unit scaling and concurrent-call isolation. | [Combined A100 comparison](https://github.com/vinli0921/vTSFM/pull/94) |

`measurements.json` contains the plotted values in their original units and links to the source experiments. To recreate the exports with Python and Matplotlib, run `python render.py` from this directory. The IEEE template can include a vector figure with `\includegraphics[width=\linewidth]{figures/02-timesfm-cuda-graphs.pdf}`.
