# vTSFM presentation figures

Each figure is available as a vector PDF for the paper and a high-resolution PNG for slides. The November 25 experiments use the same A100 and name the serving revision for each comparison. Earlier figures keep their original device, workload and baseline.

For the presentation, start with the cost of serving an individual forecast, then introduce concurrent arrivals to show when requests can share a model call. Next compare two ways to reduce execution overhead, TimesFM CUDA graph replay and Toto whole-forecast compilation. Close with Moirai to show why faster kernels and finer scheduling still need independent numerical checks on the actual workload.

### What to put on the main slide

With four slots and single-series B1/C2048/H96 arrivals offered at 80 requests/s, all three models completed more forecasts when the worker fused compatible requests into one model call. Both throughput columns use four slots, so their ratio measures the effect of fusion on this trace.

| Model | Four unfused (req/s) | Four fused (req/s) | Throughput ratio | Worst fused p99 from arrival |
| --- | ---: | ---: | ---: | ---: |
| TimesFM | 11.62 | 41.76 | 3.59× | 1,335 ms |
| Toto | 14.89 | 49.89 | 3.35× | 1,024 ms |
| Moirai | 28.86 | 76.07 | 2.64× | 150 ms |

The comparison covers four server orders on one A100, 100 requests per point per order and 28,800 timed responses across the full matrix. All timed responses passed the same independent native-output check. Rates are completions divided by elapsed wall time. The p99 column takes the worst of the four per-order p99s. The worker runtime matches main at `2e13348`; the measurement harness is at `e7e30de`. TimesFM’s native HTTP baseline uses the upstream forecast-configuration call on each request, with PyTorch compilation disabled. [Matched measurements](data/serving-matrix-a100.csv)

The `data/` directory contains the November 25 measurements. [measurements.json](measurements.json) contains the earlier values and source links. From this directory, run `python render.py` for the earlier figures, `python current.py` for the November 25 Moirai/Toto studies and `python fresh_matrix.py` for the three-model serving comparison. These commands use Python and Matplotlib. The IEEE template can include a vector figure with `\includegraphics[width=\linewidth]{figures/02-timesfm-cuda-graphs.pdf}`.
